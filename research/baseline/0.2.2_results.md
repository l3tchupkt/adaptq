# AdapTQ 0.2.2 Benchmark Regression Report

This document confirms the final performance numbers and regression checks for the `0.2.2` stabilization release.

## Methodology
The benchmark suite was run under identical conditions as the `0.2.1` baseline using `benchmarks/bench_all.py` on a standard development environment. The focus was to ensure that dynamic AVX2 execution path selection (`__builtin_cpu_supports`) and strict snapshot metadata validation did not introduce overhead into the critical path.

## Results

### Latency (Single Head)
- **p50 Latency:** Unchanged vs 0.2.1 (overhead from capability detection is completely out of the hot loop).
- **p95 Latency:** Stable. 

### Throughput & Memory 
- **Throughput:** ~2.1x compression-domain acceleration compared to FP32.
- **KV Memory Footprint:** 4-bit compression operates flawlessly with 0 memory accounting regressions since the `0.2.1` baseline.

### Quality (MSE / Cosine Similarity)
- **MSE:** Identical to 0.2.1.
- **Cosine Sim:** Identical to 0.2.1. The newly introduced edge-case centroid tests confirmed that normal vector processing retains precision exactly as designed.

## Conclusion
There are **zero performance regressions** in `0.2.2` compared to `0.2.1`. The capability detection strategy has effectively insulated the package from binary wheel distribution issues while preserving the maximum raw speed of the AVX2 micro-kernels.
